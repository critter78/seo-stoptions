# Team Mamba portraits

Drop the final portrait images for each agent in this folder. They'll be picked
up automatically by the dashboard — no code changes needed.

## Filename convention

Either of these works:

| Agent | Internal key | First-name option |
| --- | --- | --- |
| 🔎 Kira Nakamura | `researcher.png` | `kira.png` |
| 🧠 Cassius Reed | `analyst.png` | `cash.png` |
| 📣 Maya Vega | `seo_marketer.png` | `maya.png` |

Accepted extensions: `.png`, `.jpg`, `.jpeg`, `.webp`.

## Recommended specs

- **Aspect ratio:** 4:5 vertical (matches the MidJourney `--ar 4:5` prompts)
- **Resolution:** 1024×1280 minimum, 2048×2560 if you have it
- **Format:** PNG or WebP (lossless looks best on the Crew page)

## Where they show up

- **Sidebar** of the main app — small circular avatar next to each name
- **👥 The Crew page** — full-size portrait above the bio
- **Live progress** during a crew run — small avatar next to "Kira is gathering evidence…"

## Until you drop them in

The dashboard falls back to the emoji + role badge so nothing looks broken.
